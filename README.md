# GREK-BOT 格雷克机器人
> 自研人形机器人项目，搭载 NVIDIA GR00T 大模型，内置高斯泼溅3D重建模组，胸腔预留CNC加工内腔，支持爆炸式零件拆分展示

## ✨ 核心特性
- 大脑：NVIDIA GR00T 人形机器人基础模型，搭配 RTX Spark 算力模组
- 视觉：高斯泼溅（Gaussian Splatting）实时3D点云重建模组
- 结构：模块化可拆分机械结构，全部零件支持混元3D爆炸视图拆解
- 加工：胸腔内腔CNC定制加工，兼容3D打印+机加工两种工艺
- 配套：完整BOM物料清单、装配图纸、八视图参考模型

## 📁 仓库目录规划
- `/3d-models`：腾讯混元3D导出GLB模型、STL零件文件、爆炸拆分工程
- `/bom`：BOM物料清单（CSV），Tnkr AI联动绑定零件
- `/docs`：装配教程、机械说明、电路接线文档
- `/code`：GR00T部署脚本、控制固件、视觉重建代码
- `/render`：渲染图、三视图、爆炸效果图

## 🛠️ 协作平台
本项目同步接入 Tnkr AI，可在线预览3D模型、爆炸拆解、BOM零件绑定
